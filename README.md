# Armor1 Boundary for Homebrew

```
brew install armor1ai/boundary/armor1-boundary
armor1-boundary login
```

Type the full name: Homebrew asks before trusting a tap that isn't official, and naming the formula in full trusts
this one formula.

Upgrade with `brew upgrade armor1ai/boundary/armor1-boundary`. Apple silicon Macs only. Boundary needs Docker Desktop
or OrbStack and the Xcode Command Line Tools.

The formula here is written by the Boundary release; don't edit it by hand.
